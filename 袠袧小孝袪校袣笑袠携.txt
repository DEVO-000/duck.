================================================================================
        БОТ ВЫРАВНИВАНИЯ И УЛУЧШЕНИЯ ИЗОБРАЖЕНИЙ — ИНСТРУКЦИЯ (движок v2)
================================================================================

Что умеет (всё автоматически, по одному фото):
  1) разворачивает кадр, снятый боком (текст вертикально);
  2) находит границы документа/доски и исправляет перспективу и трапецию;
  3) выравнивает по горизонтали И вертикали (наклон по строкам текста,
     точность ~0.1 градуса);
  4) выпрямляет изгиб страницы и остаточную трапецию ПОСТРОЧНО (dewarp) —
     даже когда границы объекта не видны в кадре;
  5) выравнивает вертикальные линии (клетка, поля, края);
  6) делает фон однотонным (без теней, виньетки, разводов), повышает
     чёткость и качество.

Движок откалиброван на 70 реальных фото тетрадей/учебников/досок.

--------------------------------------------------------------------------------
ЧАСТЬ 1. ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ (Windows / macOS / Linux)
--------------------------------------------------------------------------------

  Шаг 1. Установите Python 3.10 или новее с https://python.org
         (в Windows при установке отметьте галочку «Add Python to PATH»).

  Шаг 2. Запустите:
         Windows:  двойной клик по run_local.bat
         macOS/Linux:  bash run_local.sh
         Скрипт сам создаст виртуальное окружение, установит зависимости
         (flask, opencv, numpy) и запустит сайт.

  Шаг 3. Откройте в браузере:  http://127.0.0.1:5000
         Перетащите фото → нажмите «Обработать» → скачайте результат.

  Обработка одного файла без сайта (из папки image-bot):
         python bot_processor.py вход.jpg результат.jpg

  Что видно на сайте после обработки (строки-«чипсы»):
         • «кадр снят боком — повёрнут на 90 град.»
         • «границы найдены — перспектива и трапеция исправлены»
         • «наклон N град. исправлен — строки горизонтальны»
         • «изгиб строк выпрямлен (разброс X -> Y град.)»
         • «трапеция/перспектива строк выпрямлена»
         • «вертикальные линии выровнены»
         • «качество: шум убран, фон однотонный, свет выровнен…»

--------------------------------------------------------------------------------
ЧАСТЬ 2. ЗАПУСК НА RENDER.COM (постоянная ссылка в интернете)
--------------------------------------------------------------------------------

  Шаг 1. Зарегистрируйтесь на https://render.com (бесплатно).

  Шаг 2. Создайте аккаунт/репозиторий на https://github.com (если нет).
         Создайте новый репозиторий (например, image-bot).

  Шаг 3. Загрузите файлы проекта в репозиторий:
         на странице репозитория «Add file» → «Upload files»
         → перетащите ВСЁ содержимое папки image-bot
         (app.py, bot_processor.py, requirements.txt, render.yaml,
          templates/index.html) → «Commit changes».

  Шаг 4. В Render: «New +» → «Web Service» → подключите репозиторий.
         Заполните:
           Name:         любое имя (оно войдёт в ссылку)
           Environment:  Python 3
           Build Command:  pip install -r requirements.txt
           Start Command:  gunicorn app:app --bind 0.0.0.0:$PORT
           Instance Type:  Free

  Шаг 5. Нажмите «Create Web Service». Через 3–5 минут по ссылке
         https://<имя-сервиса>.onrender.com будет работать тот же сайт.

  Вариант проще: в репозитории лежит render.yaml — тогда в Render можно
  «New +» → «Blueprint» и команды заполнятся автоматически.

  Важно знать:
   • бесплатный тариф «засыпает» после ~15 минут без обращений;
     первое открытие после сна занимает ~30–60 секунд — это нормально;
   • обработка одного фото — примерно 5–15 секунд;
   • форматы JPG/PNG, до 25 МБ. Фото с iPhone в HEIC сначала сохраните
     как JPG (открыть Фото → Поделиться → Сохранить как / конвертер).

--------------------------------------------------------------------------------
ЧАСТЬ 3. НАСТРОЙКА ПОД СЕБЯ
--------------------------------------------------------------------------------

Все параметры — в файле bot_processor.py:

  • шумоподавление:    denoise(result, 5.0)   — сила (0 = выключить)
  • контраст/свет:     balance_light(..., clahe_clip=2.0)
  • резкость:          sharpen(result, 0.7)   — сила
  • поиск границ:      find_document_contour(..., min_area_ratio=0.10)
                       — минимальная доля объекта в кадре
  • чувствительность dewarp: в dewarp_lines порог spread >= 0.5
                       (меньше = сильнее реагирует на мелкий изгиб)
  • заливка фона:      whiten_background(result, tolerance=50)

После правок перезапустите сайт (или задеплойте заново на Render).

--------------------------------------------------------------------------------
ЧАСТЬ 4. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------

  В: Фото с iPhone не загружается.
  О: Формат HEIC. Сохраните как JPG: открыть в «Фото» → Поделиться →
     «Сохранить как изображение» (или любой конвертер HEIC → JPG).

  В: Сколько ждать?
  О: 5–15 секунд на фото. На бесплатном Render после «сна» — плюс до минуты
     на пробуждение сервиса.

  В: Бот испортил фото, можно вернуть?
  О: На сайте показывается «До/После» — просто не скачивайте результат.
     Оригинал никогда не изменяется.

  В: Страница снята вверх ногами.
  О: Бот разворачивает кадры, снятые боком (90°), но рукописный текст
     «вверх ногами» (180°) надёжно не распознаёт — поверните фото до загрузки.

  В: Нужен размер больше 3000 px.
  О: Поменяйте MAX_SIDE = 3000 в app.py (учтите: время обработки растёт).
