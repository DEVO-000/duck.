==========================================================================
  ИНСТРУКЦИЯ: Бот выравнивания и улучшения изображений (версия 2)
  Дообучен на 70 ваших фотографиях: тетради в клетку, распечатки,
  учебники — на столе, скатерти, ткани.
==========================================================================

Что бот делает с загруженным фото — всё автоматически:
  1. Находит границы страницы (даже на пёстрой скатерти или тёмном
     столе) и исправляет ПЕРСПЕКТИВУ и ДЕФОРМАЦИЮ.
  2. Определяет угол наклона и выравнивает по ГОРИЗОНТАЛИ и ВЕРТИКАЛИ.
  3. Приводит бумагу к ОДНОТОННОМУ БЕЛОМУ ФОНУ — эффект сканера:
     клетка тетради бледнеет, тени и разводы исчезают, текст чёткий.
  4. Убирает ЖЁЛТЫЙ оттенок, шум, повышает ЧЁТКОСТЬ.
  5. Обрезает тёмный мусор по краям (переплёт книги, рука, тень).

Кнопки на сайте: «90° / 180° / отразить» — если фото перевёрнуто
или зеркально (так бывает со съёмкой на фронтальную камеру),
поверните его до обработки.

--------------------------------------------------------------------------
ЧАСТЬ 1. ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ (1 минута)
--------------------------------------------------------------------------

Windows:
  1. Установите Python 3.10 или новее с сайта https://python.org
     ВАЖНО: при установке поставьте галочку "Add Python to PATH".
  2. Откройте папку image-bot и запустите двойным кликом файл:
         run_local.bat
     (первый запуск скачает зависимости — нужен интернет, ~1 минуту)
  3. Откройте в браузере:  http://127.0.0.1:5000
  4. Перетащите фото -> нажмите "Обработать" -> "Скачать результат".

macOS / Linux:
  1. Установите Python 3.10+ (обычно уже есть).
  2. В терминале, из папки image-bot:  bash run_local.sh
  3. Откройте в браузере:  http://127.0.0.1:5000

Обработка файлов БЕЗ сайта (пакетно):
     python bot_processor.py вход.jpg результат.jpg

--------------------------------------------------------------------------
ЧАСТЬ 2. ЗАПУСК НА RENDER.COM (постоянная ссылка в интернете)
--------------------------------------------------------------------------

Бесплатный план Render подходит для начала. Сайт будет доступен по ссылке
вида https://image-align-bot.onrender.com — можно открыть с телефона.

Шаг 1. Заведите аккаунты:
  - https://github.com  (там будет храниться код)
  - https://render.com  (там будет работать бот)

Шаг 2. Создайте репозиторий на GitHub:
  - Нажмите "+" справа вверху -> "New repository".
  - Имя: image-align-bot (или любое). Тип: Public.
  - Нажмите "Create repository".

Шаг 3. Загрузите файлы проекта:
  - На странице репозитория нажмите "uploading an existing file".
  - Перетащите в окно ВСЁ СОДЕРЖИМОЕ папки image-bot:
        app.py, bot_processor.py, requirements.txt, render.yaml,
        run_local.bat, run_local.sh, README.md, ИНСТРУКЦИЯ.txt
        и папку templates (с файлом index.html).
    ВАЖНО: папка примеры не нужна — загружать её не обязательно.
  - Нажмите "Commit changes".

Шаг 4. Создайте сервис в Render:
  - В Render нажмите "New +" -> "Web Service".
  - Подключите аккаунт GitHub и выберите репозиторий image-align-bot.
  - Имя: image-align-bot (любое).
  - Region: Frankfurt (EU) — ближе к вам.
  - Branch: main.
  - Build Command:  pip install -r requirements.txt
  - Start Command:  gunicorn app:app --bind 0.0.0.0:$PORT
  - Instance Type: Free.
  - Нажмите "Create Web Service".

Шаг 5. Подождите 3-5 минут (установка библиотек).
  Вверху появится статус "Live" и ссылка на сайт — готово!
  Ссылку можно сохранить в телефон и отправлять фото откуда угодно.

Что важно знать про бесплатный план Render:
  - После ~15 минут бездействия сервис "засыпает". Первый запуск
    после сна занимает 30-60 секунд — это нормально.
  - В месяц даётся 750 бесплатных часов — для одного бота хватает.
  - Если нужен бот, который никогда не спит, — план Starter ($7/мес).

Обновление бота: изменили файл -> загрузили в GitHub тем же способом
(Commit changes) -> Render сам переустановит и перезапустит сервис.

--------------------------------------------------------------------------
ЧАСТЬ 3. НАСТРОЙКА ПОД СЕБЯ
--------------------------------------------------------------------------

Все параметры — в файле bot_processor.py:

  scan_clean(...):
     whiten_from=208   сила «однотонности»: 195 = клетка исчезает
                       совсем, 220 = мягко, фон лишь светлеет

  enhance/denoise:
     denoise_h=5.0     сила шумоподавления (0 = выкл)
     clahe_clip=2.0    сила выравнивания света и контраста
     sharpen=0.7       сила резкости (0.4 = мягче, 1.0 = сильно)

  find_document_contour(...):
     min_area_ratio=0.15  минимальная доля страницы в кадре

После изменения файла перезапустите бота (локально — заново
запустить run_local.bat; на Render — Commit changes в GitHub).

--------------------------------------------------------------------------
ЧАСТЬ 4. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------

  Фото перевёрнуто или текст зеркальный?
    Используйте кнопки «90° / 180° / отразить» на сайте ДО обработки.
    Так бывает со съёмкой на фронтальную камеру телефона.

  Файл с iPhone не загружается?
    Это формат HEIC. Откройте фото -> "Поделиться" -> "Дублировать как
    JPEG", либо в настройках камеры выберите "Формат: Совместимость".

  Бот не исправил перспективу?
    Документ должен занимать больше ~15% кадра и быть виден целиком.
    Сделайте фото так, чтобы лист был в кадре целиком.

  Страница книги изогнута волной (у корешка)?
    Исправляются наклон и трапеция перспективы. Сильный изгиб
    переплёта требует других алгоритмов — если нужно, напишите.

  Сколько занимает обработка?
    Обычное фото 2-4 секунды; большие файлы до ~10 секунд.

  Лимиты?
    Файл до 25 МБ, JPG/PNG/WebP. Больше 3000 px по стороне —
    автоматически уменьшается до 3000 px.
