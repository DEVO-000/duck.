# Бот выравнивания и улучшения изображений

Что бот делает автоматически:

- находит границы листа и исправляет **перспективу и деформацию**
  (4-точечное преобразование). Граница ищется по ЦВЕТУ листа (геодезическая
  реконструкция фона) — работает даже на светлом столе, почти не отличимом
  от бумаги по яркости;
- обрезает кадр **«только лист»**: повёрнутый прямоугольник маски листа
  выпрямляет и обрезает одним махом. Если у кромки замечен текст — рамка
  расширяется: контент важнее чистоты кромки;
- определяет угол наклона и **выравнивает по горизонтали и вертикали**:
  проекционные профили строк текста (знак надёжен, диапазон ±12°) + линии
  Хафа как подстраховка на малых углах;
- повышает **чёткость и качество**: шумоподавление, выравнивание освещённости
  плоским полем (тени и виньетка), однотонный белый фон страницы,
  мягкая резкость;
- если снимок получился «на боку» или «вверх ногами» — кнопка
  **«Повернуть»** рядом с результатом (поворачивает на 90° за клик и
  обрабатывает заново).

Протестировано на 70 реальных фото конспектов, тетрадей, аттестатов
и распечаток: перспектива находится на 66 из 70, знак выравнивания
не ошибается, фон вокруг листа убирается, контент у кромки не теряется.

## Запуск на своём компьютере

1. Установите Python 3.10+ с https://python.org
   (в Windows при установке отметьте «Add Python to PATH»).
2. Запустите `run_local.bat` (Windows) или `bash run_local.sh` (macOS/Linux) —
   скрипт сам установит зависимости и поднимет сайт.
3. Откройте в браузере http://127.0.0.1:5000, загрузите фото, нажмите «Обработать».

Обработка одного файла без сайта:

```
python bot_processor.py вход.jpg результат.jpg
```

## Запуск на Render.com (постоянная ссылка в интернете)

1. Зарегистрируйтесь на https://render.com.
2. Создайте репозиторий на GitHub и загрузите в него файлы проекта:
   на странице репозитория «Add file» → «Upload files» — можно перетащить
   сразу всю папку `image-bot`.
3. В Render: «New +» → «Web Service» → подключите этот репозиторий.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
6. Нажмите «Create Web Service». Через несколько минут бот будет доступен
   по ссылке вида `https://<имя-сервиса>.onrender.com`.

Примечания:

- бесплатный тариф Render «засыпает» после ~15 минут без обращений;
  первое обращение после сна занимает ~30–60 секунд;
- файлы: JPG или PNG, до 25 МБ (HEIC с iPhone предварительно сохраните как JPG);
- в репозитории лежит `render.yaml` — при желании можно создать сервис через
  «New +» → «Blueprint», тогда команды заполнятся сами.

## Настройка под себя

Параметры — в функциях `bot_processor.py`:

- `denoise_h` — сила шумоподавления (больше = чище, но медленнее; 0 = выкл.);
- `clahe_clip` — сила выравнивания освещённости и контраста;
- `sharpen` — сила повышения резкости;
- `min_area_ratio` — минимальная доля объекта в кадре, чтобы исправлять перспективу;
- пороги «похожести на лист» — в `page_mask` / `_page_distance`
  (адаптируются автоматически под светлый/тёмный стол).

Известные ограничения:

- сильно ИЗОГНУТЫЕ (волнистые) страницы выравниваются частично — полностью
  «распрямить» бумагу может только развёртка по сетке, её в боте нет;
- если рядом лежит ДРУГОЙ лист того же цвета (разворот тетради), бот может
  оставить обе страницы — различить их по цвету невозможно;
- ориентацию 90°/180° бот не угадывает сам (надёжного детектора без OCR нет) —
  используйте кнопку «Повернуть».
