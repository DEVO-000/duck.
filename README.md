# Бот выравнивания и улучшения изображений

Версия 2 — дообучена на 70 реальных фотографиях пользователя
(тетради в клетку, распечатки, учебники на столе и пёстрой скатерти).

Что бот делает автоматически:

- находит границы страницы даже на пёстрой скатерти и тёмном столе
  (детектор «бумаги» по насыщенности и яркости) и исправляет
  **перспективу и деформацию** (4-точечное преобразование);
- определяет угол наклона и **выравнивает по горизонтали и вертикали**
  (взвешенная по длине линий оценка — почерк не путается с наклоном кадра);
- **однотонный белый фон** (режим сканера): бумага к чистому белому,
  клетка тетради бледнеет, текст сохраняет контраст;
- **баланс белого**: убирает жёлтый/синий оттенок бумаги;
- **чёткость и качество**: шумоподавление, выравнивание света и теней,
  обрезка тёмных полос (переплёт, рука), резкость.

Интерфейс: кнопки поворота и зеркального отражения — для перевёрнутых
или зеркальных снимков (например, с фронтальной камеры телефона).

## Запуск на своём компьютере

1. Установите Python 3.10+ с https://python.org
   (в Windows при установке отметьте «Add Python to PATH»).
2. Запустите `run_local.bat` (Windows) или `bash run_local.sh` (macOS/Linux) —
   скрипт сам установит зависимости и поднимет сайт.
3. Откройте в браузере http://127.0.0.1:5000, загрузите фото, нажмите «Обработать».

Обработка одного файла без сайта:

```
python bot_processor.py вход.jpg результат.jpg
```

## Запуск на Render.com (постоянная ссылка в интернете)

1. Зарегистрируйтесь на https://render.com.
2. Создайте репозиторий на GitHub и загрузите в него файлы проекта:
   «Add file» → «Upload files» — перетащите содержимое папки `image-bot`
   (app.py, bot_processor.py, requirements.txt, render.yaml, папку templates и т.д.).
3. В Render: «New +» → «Web Service» → подключите репозиторий.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
6. Нажмите «Create Web Service». Через несколько минут бот доступен
   по ссылке `https://<имя-сервиса>.onrender.com`.

Примечания:

- бесплатный тариф Render «засыпает» после ~15 минут без обращений;
  первое обращение после сна занимает ~30–60 секунд;
- файлы: JPG или PNG, до 25 МБ (HEIC с iPhone предварительно сохраните как JPG);
- в репозитории лежит `render.yaml` — можно создать сервис через
  «New +» → «Blueprint», команды заполнятся сами.

## Настройка под себя

Параметры — в `bot_processor.py`:

- `scan_clean(whiten_from=208)` — сила однотонности: меньше значение =
  сильнее отбеливание (клетка исчезает совсем), больше = мягче;
- `denoise_h=5.0` — сила шумоподавления (0 = выкл);
- `clahe_clip=2.0` — сила выравнивания света;
- `sharpen(amount=0.7)` — сила резкости;
- `min_area_ratio=0.15` — минимальная доля страницы в кадре.

## Известные ограничения

- Зеркальные и перевёрнутые снимки бот не разворачивает сам — используйте
  кнопки «90° / 180° / отразить» на сайте до обработки.
- Сильный изгиб страницы книг (волной) полностью не распрямляется —
  исправляются наклон и трапеция перспективы.
- Пальцы и посторонние предметы поверх текста остаются на фото.
