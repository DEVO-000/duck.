# 📄 TG-сканер документов + AI (Telegram-бот)

Telegram-бот, повторяющий **все функции** оригинального веб-приложения
**Smart Document Scanner & AI Text Enhancer (TA-SCANNER)** — но вместо Flask-сайта
общение происходит прямо в Telegram.

## Что умеет бот (соответствие оригиналу)

| Функция оригинала | В боте |
|---|---|
| Загрузка изображения (PNG/JPG/JPEG/WEBP, до 16 МБ) | Пришлите **фото** или **файл** в чат |
| Перспективная коррекция документа (4-point transform, «как сканер») | Автоматически при получении изображения |
| Фильтры: Ч/Б (adaptive threshold) / серый / цвет | Фильтр по умолчанию `/filter` + кнопка «🎨 Сменить фильтр» под каждым результатом (пересчёт заново) |
| OCR через Tesseract | Автоматически, языки **русский + английский** (авто) |
| AI-улучшение текста (Llama/Replicate в оригинале) | Встроенная LLM GLM — работает **без сторонних API-ключей** |
| Показ сырого и AI-текста | AI-текст приходит сразу, сырой — по кнопке «📋 Сырой текст» |
| Скачивание обработанного изображения | Кнопка «⬇️ Скачать JPG» (файлом, без сжатия) |
| Копирование текстов | Текст присылается сообщением — копируется целиком |

**Дополнительно (новые возможности):**
- **/pdf** — собирает все отмеченные страницы в один PDF-файл (кнопка «➕ В PDF»)
- **/clear** — очистить очередь PDF и историю
- Длинные тексты автоматически режутся на несколько сообщений
- Если границы документа не найдены — обработается всё изображение целиком (бот не падает)

## Команды бота

| Команда | Описание |
|---|---|
| `/start`, `/help` | приветствие и справка |
| `/filter` | выбрать фильтр по умолчанию (Ч/Б / серый / цвет) |
| `/pdf` | собрать очередь страниц в один PDF |
| `/clear` | очистить очередь PDF и историю результатов |

## Быстрый старт

### 1. Получите токен бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`, придумайте имя и username
3. Скопируйте токен вида `123456789:AAHf3xxxxxxxxxxxxxxxxxxxxx`

### 2. Пропишите токен
В файле `.env`:
```
BOT_TOKEN=123456789:AAHf3xxxxxxxxxxxxxxxxxxxxx
```

### 3. Установите зависимости
```bash
# Tesseract OCR — обязателен (в оригинале тоже требовался)
sudo apt install tesseract-ocr            # Debian/Ubuntu
# brew install tesseract                  # macOS

pip install -r requirements.txt
```
> Русский язык OCR уже включён: файлы `tessdata/rus.traineddata` лежат в проекте.

### 4. Запустите
```bash
python bot.py
```
Бот запустится и будет отвечать в Telegram, пока работает процесс.

```
├── .env             # BOT_TOKEN и настройки
├── requirements.txt # Python-зависимости
└── README.md
```

## Технологии

- **Python 3**, `python-telegram-bot` 22 (async)
- **OpenCV** — перспективная коррекция, фильтры (код из оригинала)
- **Pytesseract / Tesseract 5** — OCR (rus+eng)
- **GLM (LLM)** — очистка и форматирование OCR-текста (промпт сохранён из оригинала)
- **Pillow** — сборка PDF

## Отличия от оригинала

1. **AI без Replicate**: вместо `meta/llama-2-13b-chat` через Replicate API
   используется встроенная LLM (GLM). Системный промпт очистки текста взят из
   оригинального `app-ocr.py`. Не нужен платный API-ключ.
2. **OCR rus+eng**: в оригинале был только `lang='eng'`, бот распознаёт русский и английский автоматически.
3. **Надёжность**: если 4-угольный контур документа не найден, оригинал возвращал
   ошибку — бот обрабатывает всё изображение целиком и честно предупреждает об этом.
4. Если AI-текст совпадает с сырым, бот сообщает, что текст уже был чистым.
