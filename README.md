# DocScan — обработка фото документов

Набор инструментов для подготовки фотографий и сканов документов к распознаванию
текста. Работает **без предварительного обучения** — на классических алгоритмах
компьютерного зрения, которые устойчивы к разным типам листов.

## Какие проблемы решает

| Проблема | Модуль | Что делает |
|---|---|---|
| Теряются буквы при распознавании | `docscan/enhance.py` | Увеличивает мелкие фото до 1600 px, убирает шум, выравнивает освещение (CLAHE), повышает резкость; режим `strong` делает чистую бинаризацию |
| Неправильно определяются границы листа | `docscan/boundary.py` | Находит контур страницы и 4 угла (3 запасных способа, если первый не сработал) |
| Лист лежит криво / под наклоном | `docscan/deskew.py` | Выравнивает лист ровно по углам (перспективная коррекция) и доворачивает строки текста до горизонтали (точность ~0.1°) |

## Установка

Нужен Python 3.8+.

```bash
pip install -r requirements.txt
```

Опционально — распознавание текста (режим `--ocr`):

```bash
pip install pytesseract
# Windows: установщик https://github.com/UB-Mannheim/tesseract/wiki (отметьте язык rus)
# Linux:   sudo apt install tesseract-ocr tesseract-ocr-rus
# macOS:   brew install tesseract tesseract-lang
```

## Быстрый старт

Одна фотография (результат в папке `docscan_output`):

```bash
python -m docscan.cli фото.jpg
```

Все фотографии из папки:

```bash
python -m docscan.cli папка_с_фото -o результат
```

С распознаванием текста и сохранением каждого этапа (углы, обрезка, выравнивание):

```bash
python -m docscan.cli фото.jpg -o результат --ocr --debug
```

Плохая печать, тени, грязный лист — жёсткая чёрно-белая обработка:

```bash
python -m docscan.cli фото.jpg -o результат --mode strong
```

В Windows можно просто перетащить файл на `run.bat`. В Linux/macOS — `./run.sh фото.jpg`.

## Что получается на выходе

```
docscan_output/
├── фото_scan.png          # итоговый выровненный улучшенный лист
├── фото.txt               # распознанный текст (если был --ocr)
└── фото_debug/            # (если был --debug)
    ├── 01_original.png    # как было
    ├── 02_corners.png     # найденные углы листа (зелёные точки, красная рамка)
    ├── 03_cropped.png     # после выравнивания по углам
    ├── 04_deskewed.png    # после доворота строк
    └── 05_enhanced.png    # после улучшения
```

Итог сохраняется в PNG — без артефактов JPEG, буквы не «замыливаются».
В режиме `soft` результат цветной, в режиме `strong` — чёрно-белый.

## Все параметры командной строки

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `input` | — | Файл или папка с изображениями (jpg, png, bmp, tif, webp) |
| `-o, --out` | `docscan_output` | Папка результатов |
| `--mode` | `soft` | `soft` — цветное улучшение; `strong` — ч/б бинаризация |
| `--no-crop` | — | Не искать границы листа |
| `--no-deskew` | — | Не доворачивать строки |
| `--no-enhance` | — | Не улучшать изображение |
| `--ocr` | — | Распознать текст (нужен Tesseract) |
| `--lang` | `rus+eng` | Языки OCR |
| `--debug` | — | Сохранять промежуточные этапы |

## Как проверить на своих примерах

1. Запустите `python selftest.py` — программа сама сгенерирует 4 тестовых
   «фото» (наклон +7°, −5°, ровный лист, лист на весь кадр), обработает их
   и покажет, что остаточный наклон после обработки меньше 1.5°.
2. Обработайте свои фото с ключом `--debug` и посмотрите `02_corners.png`:
   если зелёные точки стоят по углам листа — границы найдены верно.

## Рекомендации по съёмке (сильно влияют на результат)

- Снимайте лист **целиком**, чтобы все 4 угла были видны в кадре;
- фон вокруг листа должен контрастировать (тёмный стол / светлый лист);
- свет ровный, без сильной тени от руки или телефона;
- держите камеру параллельно листу, не под острым углом.

## Ограничения и про «обучение на 100%»

Честно: 100% точности не даёт ни один инструмент распознавания — предел
даже у промышленных систем обычно 98–99.5%. Этот набор не требует обучения
и закрывает главные источники ошибок: bad-границы, наклон, мелкий размер,
шум и неравномерный свет. Дополнительный прирост даёт Tesseract-OCR
(`--ocr`) — его при желании можно дообучать на своих шрифтах, но в большинстве
случаев правильная предобработка из этого набора уже поднимает качество
распознавания заметно сильнее, чем дообучение.

## Структура проекта

```
docscan_toolkit/
├── docscan/            # библиотека
│   ├── boundary.py     # поиск границ и углов листа
│   ├── deskew.py       # выравнивание наклона и перспективы
│   ├── enhance.py      # улучшение под OCR
│   ├── ocr.py          # Tesseract (опционально)
│   ├── pipeline.py     # конвейер обработки
│   ├── cli.py          # командная строка
│   └── utils.py        # загрузка/сохранение, координаты
├── examples/in/        # тестовые фото (создаются selftest.py)
├── examples/out/       # результаты тестов
├── selftest.py         # самопроверка
├── requirements.txt
├── run.bat / run.sh    # запуск в один клик
└── README.md
```
