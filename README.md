# Бот выравнивания и улучшения изображений (движок v2)

Что бот делает автоматически:

- **разворачивает кадр**, если он снят боком (текст вертикально — поворот на 90°);
- находит границы документа/объекта и исправляет **перспективу и трапецию**
  (4-точечное преобразование; несколько способов поиска границ — контуры,
  пороги Отсу/адаптивный, линии Хафа);
- **выравнивает по горизонтали И вертикали**: глобальный наклон определяется
  проекционным методом по строкам текста (точность до ~0.1°);
- **выпрямляет изгиб страницы и остаточную трапецию построчно** (dewarp):
  локальный наклон строк измеряется в полосах и компенсируется сдвигами —
  работает даже когда границы документа не видны;
- выравнивает **вертикальные линии** (клетка тетради, поля, края страницы);
- делает фон **однотонным**: flat-field нормализация убирает виньетку, тени,
  разводы и градиенты (белый лист — к белому, доска — ровный тон);
- повышает **чёткость и качество**: шумоподавление, выравнивание
  освещённости, обрезка белых полей, усиление резкости.

Движок откалиброван на 70 реальных фотографиях тетрадей, учебников и досок:
геометрия применяется на 100% кадров, остаточный наклон строк — доли градуса,
однородность фона улучшается в ~1.7 раза, резкость — в ~3.8 раза.

## Запуск на своём компьютере

1. Установите Python 3.10+ с https://python.org
   (в Windows при установке отметьте «Add Python to PATH»).
2. Запустите `run_local.bat` (Windows) или `bash run_local.sh` (macOS/Linux) —
   скрипт сам установит зависимости и поднимет сайт.
3. Откройте в браузере http://127.0.0.1:5000, загрузите фото, нажмите «Обработать».

Обработка одного файла без сайта:

```
python bot_processor.py вход.jpg результат.jpg
```

## Запуск на Render.com (постоянная ссылка в интернете)

1. Зарегистрируйтесь на https://render.com.
2. Создайте репозиторий на GitHub и загрузите в него файлы проекта:
   на странице репозитория «Add file» → «Upload files» — можно перетащить
   сразу всю папку `image-bot`.
3. В Render: «New +» → «Web Service» → подключите этот репозиторий.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
6. Нажмите «Create Web Service». Через несколько минут бот будет доступен
   по ссылке вида `https://<имя-сервиса>.onrender.com`.

Примечания:

- бесплатный тариф Render «засыпает» после ~15 минут без обращений;
  первое обращение после сна занимает ~30–60 секунд;
- файлы: JPG или PNG, до 25 МБ (HEIC с iPhone предварительно сохраните как JPG);
- обработка большого фото занимает ~5–15 секунд — это нормально;
- в репозитории лежит `render.yaml` — при желании можно создать сервис через
  «New +» → «Blueprint», тогда команды заполнятся сами.

## Настройка под себя

Параметры — в функциях `bot_processor.py`:

- `denoise_h` — сила шумоподавления (больше = чище, но медленнее; 0 = выкл.);
- `clahe_clip` — сила выравнивания освещённости и контраста (для белых листов);
- `sharpen` — сила повышения резкости;
- `min_area_ratio` — минимальная доля объекта в кадре, чтобы исправлять перспективу;
- пороги срабатывания dewarp — `spread >= 0.5` в `dewarp_lines`
  (меньше = чувствительнее к мелкому изгибу).

Ограничение: бот разворачивает кадры, снятые боком (90°), но не отличает
«вверх ногами» (180°) для рукописного текста — такую ориентацию поправьте
до загрузки.
