# 📄 TG-сканер документов (Telegram-бот)

Telegram-бот, повторяющий функции сканирования оригинального веб-приложения
**Smart Document Scanner & AI Text Enhancer (TA-SCANNER)** — **без AI-обработки
текста**: распознанный текст приходит целиком и в чистом виде, ровно как его
распознал Tesseract (как в веб-версии).

## Что умеет бот

| Функция | Как работает |
|---|---|
| Загрузка изображения (PNG/JPG/JPEG/WEBP, до 16 МБ) | Пришлите **фото** или **файл** в чат; EXIF-поворот учитывается |
| ✂️ Идеальное выравнивание | Перспективная коррекция (края + яркостный поиск листа, штраф за «рамку режет текст», второй проход уточнения) |
| 🧭 Авто-ориентация 0/90/180/270 | Ось текста по форме слов + СТРОГИЙ скоринг слов Tesseract (conf≥60); рукопись честно уходит в фолббек оси |
| 📐 Доворот до строго горизонтального текста | Точность до 0.05°: линии Хафа + проекционный метод, полярно-инвариантная маска чернил (работает и для мела) |
| 〰️ Исправление деформации (изгиба) | Полосовая взаимная корреляция проекций чернил -> кривизна -> обратный remap; изогнутые строки выпрямляются |
| 🧹 Чистота и качество | Нормализация освещения + медиана + бинаризация Сауволы (локальный порог с дисперсией) + удаление «плавающих точек» и мусора по кромкам |
| ⬛ Доски (мел) | Авто-полярность: мел инвертируется ДО нормализации — «мел -> чёрный текст на белом» |
| Фильтры: ⚫ Ч/Б / ◻ серый / 🎨 цвет | Фильтр по умолчанию `/filter` + кнопка «🎨 Сменить фильтр» (пересчёт заново, геометрия не «прыгает») |
| 🔍 OCR (Tesseract) | Русский + английский (авто). Текст приходит **целиком, чистыми строками** |
| 📄 / 📊 Определение типа | Бот определяет, что на листе, и **спрашивает**, если видит таблицу |
| ❓ Вопрос при таблице | «📊 Распознать таблицу» (по ячейкам) или «📄 Весь лист» (линии сетки убираются) |
| ⬇️ Скачать JPG | Кнопка под результатом — файл без сжатия Telegram |
| 📑 PDF-экспорт | Кнопка «➕ В PDF» и команда `/pdf` |

**Без AI.** Никаких внешних нейросетей и API-ключей — только OpenCV + Tesseract.

## Команды бота

| Команда | Описание |
|---|---|
| `/start`, `/help` | приветствие и справка |
| `/filter` | выбрать фильтр по умолчанию (Ч/Б / серый / цвет) |

## Как работает выравнивание (v4.1)

1. **Поиск границ листа** — 2 стратегии (3 варианта детекции краёв +
   яркостная «яркая бумага» с выпуклой оболочкой и габаритным боксом
   для изогнутых краёв). Кандидаты штрафуются, если тонкое кольцо
   внутри рамки пересекает текст («рамка режет текст») или похоже на
   фон, а не на лист (габаритный бокс вокруг наклонного листа).
2. **Второй проход уточнения**: если после первой коррекции вокруг
   листа остался фон, границы ищутся заново — лист уже выпрямлен
   и имеет ровные края.
3. Четырёхугольник **поджимается внутрь** (~2%) — по краям скана не
   остаётся полос фона.
4. **Авто-ориентация 0/90/180/270**: ось текста (блобы-слова ×
   пиковость проекции), затем строгий скоринг слов Tesseract
   (conf≥60, ≥30 символов, перевес ×2.5). На рукописи OCR честно
   «отказывается» и используется фолббек оси (0°/90°) — мягкий порог
   давал ложные срабатывания (перевёрнутая рукопись «читалась»
   лучше правильной).
5. **Перспективное преобразование** «вид сканера» (выходной размер —
   по боковым сторонам квада, без растяжения) + **финишный доворот**
   до строго горизонтального текста (до 0.05°).
6. **Выправление изгиба страницы** (dewarp): проекции чернил соседних
   вертикальных полос взаимно коррелируются -> кривизна -> обратный
   remap. Срабатывает только при уверенной гладкой кривизне.
7. Если границы не найдены — бот выравнивает наклон и обрабатывает
   весь лист. Внутренние рамки/таблицы на листе во весь кадр НЕ
   обрезаются.

## Ч/Б-фильтр (Саувола)

1. Авто-полярность: мел/белый маркер на тёмном инвертируется ДО
   нормализации освещения (иначе контраст гибнет);
2. Нормализация освещения без CLAHE/резкости (локальная статистика
   порога должна видеть настоящие штрихи);
3. Медиана 3×3 против зерна камеры;
4. Порог Сауволы T = m·(1 + k·(s/R − 1)) — самонастраивается под
   локальный контраст (карандаш, мел, печать);
5. Удаление «плавающих точек» (порог площади масштабируется с
   разрешением) и фонового мусора по кромкам (оправа доски,
   срез соседней страницы) с защитой тонких линий таблиц.

## Как определяется «страница или таблица» (и вопрос)

1. Изображение бинаризуется (Otsu), линии сетки ищутся морфологическим
   открытием **с допуском наклона ±4°** (устойчиво к перспективе).
2. Критерии таблицы строгие: ≥ 3 длинных горизонтальных и ≥ 3 вертикальных
   линий, большинство пересечений-«узлов» заполнено, сетка занимает заметную
   часть листа.
3. Если таблица обнаружена — бот **спрашивает**, что распознать:
   - **📊 Распознать таблицу** — каждая ячейка отдельно, строки через `|`;
   - **📄 Весь лист** — линии сетки убираются, OCR читает весь лист целиком.
4. Если таблица не найдена — сразу обычный OCR всей страницы.

Если ячейки таблицы не распознались — бот автоматически откатывается
к обычному OCR страницы.

## Быстрый старт

### 1. Получите токен бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`, придумайте имя и username
3. Скопируйте токен вида `123456789:AAHf3xxxxxxxxxxxxxxxxxxxxx`

### 2. Пропишите токен
В файле `.env`:
```
BOT_TOKEN=123456789:AAHf3xxxxxxxxxxxxxxxxxxxxx
```

### 3. Установите зависимости
```bash
# Tesseract OCR — обязателен
sudo apt install tesseract-ocr            # Debian/Ubuntu
# brew install tesseract                  # macOS

pip install -r requirements.txt
```
> Русский язык OCR уже включён: файлы `tessdata/rus.traineddata` лежат в проекте.

### 4. Запустите
```bash
python bot.py
```
Бот отвечает в Telegram, пока работает процесс.

## Известные ограничения

- **Рукописный текст вверх ногами (180°)**: OCR его не читает, а
  надёжной классической метрики «верх/низ» для рукописи не найдено
  (проверены асимметрия строк, автокорреляция, знаки препинания).
  Печатный текст 180° определяется уверенно. Если пришлите пример
  перевёрнутой рукописи — можно точечно дообучить.
- Доска с мелом: строки читаются, но очень бледный/стёртый мел
  физически малоинформативен — для верности используйте фильтр
  «серый».

## Технологии

- **Python 3**, `python-telegram-bot` 22 (async)
- **OpenCV** — выравнивание, Саувола, dewarp, поиск сетки таблиц
- **Pytesseract / Tesseract 5** — OCR (rus+eng), распознавание ячеек таблиц
- **Pillow** — сборка PDF

## Отличия от оригинала

1. **Без AI**: из оригинала убран шаг Llama/Replicate — текст отдаётся как есть,
   сразу после OCR (быстрее: ответ за 2–6 секунд вместо 10–40).
2. **OCR rus+eng**: в оригинале был только `lang='eng'`.
3. **Идеальное выравнивание**: многовариантный поиск контура + доворот текста
   до горизонтали + обрезка фона (в оригинале был один Canny с грубой
   аппроксимацией и без доворота).
4. **Чистые фильтры**: нормализация света, шумоподавление, удаление точек,
   сглаживание (в оригинале — «сырой» adaptive threshold с мусором).
5. **Вопрос при таблице**: бот не решает за вас — спрашивает «таблица или
   весь лист»; в режиме «весь лист» линии сетки убираются, чтобы OCR читал
   всё содержимое.
6. **Надёжность**: если 4-угольный контур документа не найден, оригинал возвращал
   ошибку — бот выравнивает наклон и обрабатывает всё изображение целиком.
